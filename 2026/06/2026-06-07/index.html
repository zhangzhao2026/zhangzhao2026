    23:18 【MrBeast官方】挑战北极极限生存7天，我做到了！

    由于我早就厌倦了在edge地址栏复制的链接中会有许多跟踪参数，在我复制了上面这个链接并输入到Obsidian中后，今天一下午都开着VPN，靠Gemini帮我解决代码问题，对AI的依赖已被点燃，所以我直接开始向AI寻求复制纯净链接的解决方案。

    我最初的设想是让AI帮我做一个代码，实时监视我的剪切板，对识别到的链接进行格式化操作，去除跟踪参数、转化为markdown语法：[网页标题](极简网络地址)。

    但是Gemini告诉我可以下载浏览器插件。于是我直接去问DeepSeek，有哪些浏览器插件可以帮我解决该问题，我得知了以下工具：

    1. Arclet Copier - 智能URL复制与分享
    2. ClearURLs - Microsoft Edge Addons
      • 很久很久之前的大学时期，这个插件就被我下载了，今天才知道使用
      • 官方规则：data.minify.json

    非目标工具

    • Url Shortener
      1. 功能强大，但需要注册、付费
      2. 可以批量缩短URL
    • Copy Title and Url as Markdown Style
      • 只能当作一键复制工具，该插件不能去除无效参数
    • Copy as Markdown
      1. 一键将当前打开的所有网页链接复制为Markdown链接（ToDo or List）、仅标题、仅链接
      2. 复制当前网页链接
      3. 只能当作一键辅助工具，该工具不能去除无效参数
    • linkmark
      • 网站收藏容器，这个插件我自己开发了，比它的功能好

    短链服务is.gd和tinyurl有什么区别？

    is.gd：追求极致的短。它的域名只有 5 个字符。完全免费且详细。免费支持自定义别名。纯粹的学院派/极客风，无需注册。提供极其简单且无门槛的 API。写Python代码的首选。 TinyURL：存在付费功能。免费支持自定义别名。现代商业化工具。需要你注册账号并携带 API Key 才能调用，且免费账户有额度限制。企业用户规范后台管理首选。
